\section*{Supplementary Type-I Witness Table}
This file preserves the full row-by-row lookup table of the 93 type-I schemes found by primitive patchworking, together with the row keys and representative counts. For a one-nest code, the table key is $(\ell,\epsilon,\Pi_+-\Pi_-,e)$, where $\ell$ is the number of ovals, $\epsilon$ is the sign of the nest oval, and $e$ is the number of exterior ovals. For $\mathsf{N}_{\mathrm I}^{+}(\kappa;s,n)$, the key is $(\kappa+1,+,t-12+2n,s)$, where $t=\kappa-s$; for $\mathsf{N}_{\mathrm I}^{-}(\kappa;s,b)$, it is $(\kappa+1,-,t-2b,s)$. The codes $\mathsf U_{\mathrm I}(r)$ and $\mathsf T_{\mathrm I}$ have keys $(r,\text{--},0,r)$ and $(3,-,-3,0)$, respectively.
